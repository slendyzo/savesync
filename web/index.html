Three steps and you're syncing.

SaveSync watches for tracked games launching and exiting. Saves are pushed to your private repo, version-controlled like code, and pulled back on every other machine.

01

Connect GitHub

Sign in via GitHub's Device Flow — type an 8-character code, approve in your browser, done. PAT fallback supported for Forgejo / GitLab / Gitea.

02

Pick or create a repo

We auto-create a private savesync-data repo on your account, or you can point at an existing one.

03

Add your games

Steam library auto-scan finds installed games with known save paths. ~13,000 games supported via the bundled Ludusavi manifest.

Newest wins. Nothing's lost.

When two machines diverge — you played offline on the ROG Ally while your PC also had unsynced progress — the older state is preserved on a labeled backup branch. You can always roll back.

Your data. Your repo. No servers.

SaveSync is a thin client over git. We don't run a backend. Every byte of save data flows from your machine to a repo on your account.

No telemetry

SaveSync doesn't phone home. It connects to GitHub (or your chosen host) and that's it.

OS keychain only

Your GitHub token is stored in Keychain / Credential Manager / Secret Service — never on disk in plaintext, never transmitted anywhere except GitHub.

Open source

Every line of code is on GitHub. Audit the sync engine, the auth flow, the file-watcher — all of it.

Install

Portable binaries — no installer, no admin rights needed. Drop the .exe on your desktop, drop the AppImage on your Linux box, you're done.

windows

Download .exe

Grab the NSIS installer or the portable .exe from the latest release. First-launch SmartScreen warning until our SignPath OSS signing lands — "More info → Run anyway".

linux

AppImage

Download the AppImage, chmod +x SaveSync*.AppImage, double-click. Works on Bazzite, SteamOS, Ubuntu, Fedora — anywhere with webkit2gtk-4.1.

updates

Self-updating

Every release auto-updates the installed version on next launch. No package manager needed.

Questions

If yours isn't here, open an issue on GitHub.

Is this for piracy?

No. SaveSync is a save-data backup tool that works identically with paid games and cracked games. It doesn't download, distribute, or modify games — it only syncs save files between machines you control. Many legit-game users in the SaveSync audience play non-Steam titles (GOG, Epic, itch, standalone launchers) that Steam Cloud doesn't reach.

Will my saves bloat my git repo?

Most game saves are tiny — Elden Ring is around 50KB, Stardew Valley is similar. SaveSync auto-routes any file over 50MB through git-lfs so big saves (RDR2, Cities Skylines) don't bloat the repo's history. The threshold is configurable in Settings.

What if I have changes on both machines?

Newest wins by save-file modification time. The older state is preserved on a labeled backup branch — backup/elden-ring/ROG-Ally-2026-05-12-2031 — so nothing is ever silently deleted. You can git checkout a backup branch to restore it.

Can I use a self-hosted git server?

Yes — anything with a /user API endpoint works. Forgejo, Gitea, GitLab, self-hosted GitHub Enterprise. Pick "Use a different host" in the wizard and paste your API base URL + personal access token.

Does it run in the background?

Yes. SaveSync stays in your system tray and watches for tracked-game processes. When a game launches, it pulls the latest save from your repo. When the game exits, it pushes the updated save. The window can be closed without quitting — the tray icon keeps it alive.

Where does my GitHub token live?

In your OS keychain — Keychain on macOS, Credential Manager on Windows, libsecret / Secret Service on Linux. It's never on disk in plaintext, never transmitted anywhere except GitHub's auth endpoints. You can revoke it any time on GitHub or click "Disconnect this machine" in Settings.

Why not just use Steam Cloud?

If your games are on Steam and the developer enabled Cloud, do that. SaveSync exists for the rest: cracked games, GOG-without-Galaxy, Epic Games Store titles without Cloud support, itch.io games, mods that store saves in odd places, anything that lives outside Steam.
