# SaveSync

Steam Cloud for any game. A portable, cross-platform desktop app that syncs
game saves across devices using a private GitHub repo as the backend. Works
with Steam, repacked games (FitGirl / DODI), GOG, Epic, itch.io — anywhere
Steam Cloud doesn't reach.

**Status:** v1 is shipping. The first release is at
[Releases](https://github.com/slendyzo/savesync/releases).
